**Real-Time Person Tracking System**

This project implements a real-time crowd safety monitoring and analysis system using YOLO for person detection and DeepSORT for multi-object tracking. The system continuously monitors crowd movement, estimates real-time crowd density, and classifies risk levels to detect potentially dangerous overcrowding situations.

The objective is to provide early warnings for crowd congestion and stampede risk, making the system applicable for public safety monitoring, surveillance analytics, and smart city applications.

**View the sample video output:**[LINK](https://drive.google.com/file/d/1X6bdeFKxsFMXe6EVnOQFGQy7gGCe38po/view?usp=sharing)

**Features**
-Real-time Person Detection using YOLO.
-Multi-Object Tracking using DeepSORT for consistent ID assignment
-Live Crowd Counting
-Dynamic Crowd Density Estimation
-Real-time Risk Classification (SAFE / MODERATE / DANGEROUS)
-Live Monitoring Dashboard using Streamlit

**Tech Stack**
Python
YOLO – Real-time object detection
DeepSORT – Multi-object tracking
OpenCV – Video processing
Streamlit – Live dashboard visualization
